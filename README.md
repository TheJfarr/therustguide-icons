# The Rust Guide icons

Item and loot icons for [The Rust Guide](https://github.com/TheJfarr/TheRustGuide), mirrored from its `public/icons/` folder so the site can serve them through the free [jsDelivr](https://www.jsdelivr.com/) CDN:

```
https://cdn.jsdelivr.net/gh/TheJfarr/therustguide-icons@<commit>/icons/<shortname>.webp
https://cdn.jsdelivr.net/gh/TheJfarr/therustguide-icons@<commit>/icons/loot/<icon>.webp
```

The site pins a full commit (`ICON_CDN_SHA` in `lib/icons.ts`), so update this repo first, then point the site at the new commit.

The icons come from the game Rust and belong to Facepunch Studios. This project is not affiliated with or endorsed by Facepunch.
